Book Reader

Open a file or drop it here.
EPUB, FB2, FB2.ZIP, PDF, TXT, HTML, MD

Book Reader is a small, minimalist book reader. It runs entirely in your browser: your files are never uploaded anywhere.

Formats: EPUB, FB2, FB2.ZIP, PDF, TXT, HTML, MD. Footnotes open in a popup; Back returns after a link jump.

Notes: select text (optional), press Notes, write and add. Export and import notes as a JSON file. Notes, reading position and settings are kept in this browser.

Keys: ← → previous / next section or page, Esc closes panels.

Main site: dontaz.com

Uses pdf.js (Apache-2.0) and JSZip (MIT). See THIRD-PARTY-LICENSES.txt.
