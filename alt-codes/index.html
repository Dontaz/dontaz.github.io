What this page is

Alt Codes is a quick reference for the special characters hiding behind the Alt key. Every entry shows three things: the glyph itself, a readable name, and the numeric code you type on the numeric keypad. Click any card and the symbol lands in your clipboard — ready to paste anywhere.

How to use it

  1. Search by name (arrow), by code (236), by category (typography) or by pasting the symbol itself (∞).
  2. Click a card to copy the symbol. A toast at the bottom confirms it.
  3. Type the code on your keyboard using the steps below if you would rather produce the character directly.

Typing the code yourself

Windows Hold Alt and type the digits on the numeric keypad, then release. Codes starting with a zero need Num Lock on and the leading zero included.
Linux Press Ctrl+Shift+U, type the hex value, then Enter.
macOS Use ⌥ Option combinations, or the Character Viewer with ⌃ Ctrl+⌘ Cmd+Space.

Four-digit codes come from the Windows ANSI table and three-digit codes from the older DOS table. Laptops without a numeric keypad usually need Fn held down — or just copy from here instead.

Why some symbols have no Alt code

Alt codes are frozen in two tables from the DOS and Windows era — CP437 and CP1252 — and both stop at 255 characters. Anything added to Unicode later simply has no numeric Alt code. The ruble sign ₽, the tenge ₸, the hryvnia ₴, the bitcoin sign ₿ and every emoji fall into this group.

Sections marked Unicode show the codepoint (U+20BD) instead of inventing a number that would not work. Those characters are one click away, and you can type them with the hex method above — on Linux that is Ctrl+Shift+U then 20bd.
